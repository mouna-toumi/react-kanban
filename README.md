# React Kanban

Application de tableau Kanban en React pour suivre des tâches sur trois colonnes : **À faire**, **En cours** et **Terminé**.

Projet d’apprentissage : gestion d’état, composants, hook personnalisé et interface inspirée d’un design system moderne (Lumina).

## Fonctionnalités

- Créer, modifier et supprimer une tâche
- Titre, description, priorité (Basse, Moyenne, Haute) et image
- Déplacer une carte d’une colonne à l’autre (glisser-déposer)
- Rechercher une tâche par titre
- Sauvegarde automatique dans `localStorage`

## Stack

- React 19
- Vite
- CSS (design system Lumina)
- Tabler Icons
- Bootstrap (base)
